# StockLens｜個人投資組合分析儀表板

StockLens 是一個以 Vibe Coding 方式完成的互動式投資組合分析 Web App。使用者可以自行建立台股與美股持股，輸入目前股價及美元匯率，系統會即時計算成本、市值、未實現損益與報酬率，並以圖表及排行榜呈現投資組合狀況。

## 作品連結

- GitHub Pages：[開啟 StockLens](https://suo030250.github.io/stocklens/)
- 完整需求規格書：[SPECIFICATION.md](./SPECIFICATION.md)
- 主程式：[index.html](./index.html)

## 核心特色

- 支援台股與美股持股的新增、編輯及刪除
- 手動設定美元兌新台幣匯率
- 自動計算總成本、目前市值、損益及報酬率
- 以圓餅圖呈現個股配置與市場配置
- 提供績效排行榜與投資集中度分析
- 使用瀏覽器 localStorage 自動保存資料
- 支援 JSON 備份匯出、匯入及一鍵清除
- 內建示範資料，方便快速體驗完整功能
- 深色金融科技風格，支援手機與電腦版面
- 整個作品整合在單一 index.html，可直接部署至 GitHub Pages

## 操作方式

1. 點選「新增持股」。
2. 選擇台股或美股，填寫股票代號、名稱、股數、平均成本與目前股價。
3. 若持有美股，可在頁面上方修改目前美元匯率。
4. 儲存後，儀表板會即時更新摘要、圖表、排行榜及集中度分析。
5. 可從持股清單編輯或刪除資料，也可將全部資料匯出為 JSON 備份。

## 使用技術

- HTML5
- CSS3
- Vanilla JavaScript
- Chart.js

- GitHub Pages

## 專案限制

- 本作品沒有後端伺服器或資料庫。
- 股票價格與匯率由使用者手動輸入，不會連接即時行情 API。
- 資料只保存在目前瀏覽器中；清除瀏覽器資料前，建議先匯出 JSON 備份。

## Vibe Coding 開發紀錄

本專案先透過 AI 進行需求討論與規格整理，再分階段完成介面、持股管理、投資計算、資料視覺化、資料保存及 GitHub Pages 部署。完成初版後，也實際測試台股、美股、匯率更新、資料持久化、重複股票阻擋、刪除確認及手機版面，並根據測試結果改善空資料畫面與瀏覽器相容性。

詳細規格、計算公式、驗收條件與功能對照請參考 [完整需求規格書](./SPECIFICATION.md)。
